模型方法、公式与参数来源 ＋

本模型假设恒定外部剂量以固定比例吸收，吸收后的物质进入单一体室，并按一级动力学消除。暴露停止后，浓度按同一消除速率下降。初始浓度 C₀ 只代表起始体内负荷，不包含持续背景暴露。

k = ln(2) / 消除半衰期； Css = F × D / (Vd × k)
暴露期间：C(t) = Css + (C₀ − Css)e−kt
停止暴露后：C(t) = C(停止时) × e−k × 停止后时间

预设半衰期和 Vd 为 Chiu 等基于饮水暴露研究得到的人群参数估计，换算按 365.25 天/年；其余参数为用户假设。若用于化妆品研究，需要独立估计产品浓度、用量、接触面积和皮肤吸收比例，不能把产品浓度直接当作体内剂量。

关于当前版本

这是小规模人工整理的研究原型，并非完整数据库，也未实时同步外部平台。未展示的化合物或关系不代表没有研究。自有样本、实验和患者级数据尚未接入。
